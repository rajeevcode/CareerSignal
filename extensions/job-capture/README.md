# CareerSignal Job Capture

Load this directory as an unpacked extension in Chrome or Edge. It requests active-tab,
scripting, and local preferences only; it has no broad browsing permissions.

Open a job posting, select the relevant text if needed, click the extension and set your
CareerSignal origin. The source text is transferred in the URL fragment (not a server
query or log). CareerSignal removes the fragment after reading it. Review the captured
fields and click Save to persist a private opportunity. Repeated URLs and identical
postings are deduplicated. This extension never submits applications or reads cookies.
